# Field Mapping

The final workbook must use the sheet and header layout of the selected official template in `assets/`. The source client form is a vertical A/B/C/D sheet; map each row's column B field name to the same-named column in the template's row 1, and write column C into it.

## Source Form Layout

| Column | Meaning |
|---|---|
| A | Unit block name (merged down the rows of that unit) |
| B | Field name |
| C | Client content to export |
| D | Fill-in guidance, examples, or image instructions; never export |

## Known Source-to-Template Aliases

The observed manufacturer source uses these different labels; map them to the official template column. Everything else maps by exact field name.

| Source field | Template column |
|---|---|
| 适合场景 | 适用场景 (对比单元) |
| 数量规模 | 项目规模 (案例单元) |

Everything else maps by exact field name. Source rows that do not correspond to a template header are left out; template headers without a source row stay blank and are reported in the separate missing checklist.

## Consistency Requirement

The English original and Chinese analysis workbooks must contain the same information:

- Same sheet names and order.
- Same row-1 field titles.
- Same filled/blank cell positions.
- Same numbers, percentages, dimensions, years, models, dates, URLs, emails, and phone numbers.
