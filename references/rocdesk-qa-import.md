# RocDesk 九大内容单元问答导入

导入目标：[RocDesk 内容单元页面](https://marketing.rocdesk.com/geo/asset-profile?report_id=26810ffh7at0j)。本仓库的 `assets/rocdesk-nine-unit-qa-template.xlsx` 与该页面“Excel 导入”入口的 `geo_asset_import.xlsx` 范例文件 SHA-256 一致（核对日期：2026-11-13）。这是范例，不是客户资料。

## 模板结构

- 01–07：企业背景、产品规格、认证合规、应用场景、能力、案例、对比；与制造商格式的前七页对应。
- 08：知识与FAQ单元，支持操作指南、原理科普、名词定义、选型推荐、FAQ集合、故障排查。
- 09：风控与采购支持单元，支持对比评测、标准与认证、风险识别与规避、采购与选型指南。
- “填写说明”：仅供参考，不参与最终上传。模板原文件共 10 页，最终上传时保留所需的 01–09 页。

## 08/09 两页共同列结构

`内容类型 / 客户问题 / 相同问题的其他问法 / 核心回答 / 核心字段1 / 核心字段2 / 核心字段3 / 选填字段1 / 选填字段2`。一行填写一条问答，多个相同问题的其他问法可换行。核心字段的语义随内容类型变化，以模板“填写说明”中的对照表为准；不要把一种类型的字段定义套用到另一种类型。

## 交付和导入

1. 根据客户真实材料填写所需单元。模板中的 ABC Fan、RFID 安全开关、采购条款等行仅为演示，必须清除。不得把模板示例当成客户事实。
2. 08/09 的问题、回答、参数、认证、采购条款和证据应来自客户已确认的资料。没有依据的字段留空，并列入单独补充清单。
3. 导入前删除“填写说明”和不需要导入的 sheet，并清除全部示例行。保留所需 sheet 的原名、列名和列顺序。
4. RocDesk 页面分别为 08/09 提供“Excel 导入”入口；页面已显示问答记录与审核状态。模板说明声称按 sheet 名识别、每页单次最多 50 行并以客户问题去重；这些属于模板提供的规则，当前未用真实文件执行上传验证。
5. 本仓库旧“维特家九大单元流程包”的中英文实例为服务商 9 页，不包含 08/09 问答单元。它不能作为 RocDesk 问答导入实例使用。
